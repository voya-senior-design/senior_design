# Voya

Senior Design Capstone Project — A weather-based travel discovery and social itinerary platform

## 1. Project Overview

Voya is a social travel platform that helps users discover destinations, share travel experiences, and plan trips based on weather, travel dates, and budget. Users can explore itineraries, view trip costs, read recommendations, and use other travelers' experiences to plan their own trips.
